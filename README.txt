MOCHILA S.O.S. - VERSION MEJORADA PARA PRESENTACION
===================================================

Incluye:
- Inicio y navegación del prototipo.
- Listas de mochila por perfil.
- Tienda S.O.S. con catálogo demostrativo: bebé, niño, adolescente, adulto,
  adulto mayor, mascota y mochila familiar.
- Fichas desplegables con el contenido de cada modelo.
- Selección de productos para mostrar el interés de compra (sin pagos reales).
- Fenómenos naturales con recomendaciones antes, durante y después.
- Mapa, herramientas de ubicación y asistente guiado del prototipo.
- Logo original del proyecto.

PARA ABRIR:
1. Extrae el ZIP.
2. Abre la carpeta MOCHILASOS2-main.
3. Abre index.html en un navegador.

PARA PUBLICAR EN GITHUB PAGES:
Sube el contenido de esta carpeta a la raíz del repositorio publicado.

IMPORTANTE:
- La tienda es una demostración del modelo de ingresos; no procesa pagos ni
  confirma pedidos reales.
- El mapa y la ubicación requieren permisos y/o conexión.
- El asistente es guiado y no es una IA generativa conectada.
- La señal hablada depende de que el navegador admita síntesis de voz.
- Las zonas del mapa son ilustrativas, no mapas oficiales de riesgo.
- La información de salud es general y no reemplaza indicaciones profesionales.
